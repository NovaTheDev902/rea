# Native Framework

Clean, unified native framework consolidating reversed samples:
- `coruna/` — Coruna (kernel, implant, persist, extra, bootstrap, plasmaloader, stages)
- `graphite/` — Graphite (core engine, AMR, CVEs)
- `pegasus/` — Pegasus (native Android, C2, implant)

Each subdirectory has `include/` (headers) and `src/` (implementation).
